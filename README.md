# FocusTools
A minimalist website with neccessary tools for a deep, focused work.

## How to open
Open up a web-browser and navigate to index.html, e.g. file:///home/alex/programming/FocusTools/index.html
or run from terminal, e.g. 
`brave-browser index.html`
